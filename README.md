# 需求日历

面向程序员的需求排期与资料管理交互原型。

## 预览

下载仓库后，用现代浏览器打开 `index.html`。无需安装依赖。

`src/calendar.html` 保留可读的界面源码，`index.html` 是带独立运行环境的导出版本。

## 已有交互

- 默认月历，支持切换月份；顶部加号创建需求。
- 点击日期或拖动日期范围创建需求，支持反向拖动和跨周。
- 需求以连续的跨日长条展示，评审、开发、测试等阶段显示在需求条内部。
- 点击需求查看详情，支持编辑名称、周期、阶段、事项与备忘。
- 自定义资料名称、类型和链接。
- 创建和编辑时保留彩色范围条，修改起止日期实时更新；取消清除预览，保存后显示正式需求。
- 紧凑的编辑面板，基本信息中合并资料，超长内容在面板内滚动。
- 适配浅色和深色外观，并尊重减少动态效果的系统偏好。

## 当前范围

目前是 HTML/CSS/JavaScript 交互原型，内置示例需求。原型最多保存 16 个需求，浏览器数据保存采用独立运行环境提供的本地存储。

macOS 原生通知、菜单栏、开机启动、后台提醒、数据库和浏览器标签页图标获取，仍需要后续应用工程实现。

仓库不包含账号凭证或聊天记录。

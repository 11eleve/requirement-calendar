# 50 轮优化记录

目标：改善交互体验与桌面原生体验；仅增加程序员管理需求所需的功能。每轮需有实际改动和验证，不以重复检查或重命名充数。

持续保留：月历主视图、顶部单一加号、连续需求长条、条内阶段、自定义资料、紧凑滚动编辑器、点击/正反拖动创建、编辑期间保留范围条、无整格选中背景、减少动态效果偏好。

## 已实现的第一批：数据可靠性（01–10）

| 轮次 | 问题与改动 | 验证证据 |
| --- | --- | --- |
| 01 | iframe 导出文件难以维护；拆分页面、样式、模型、存储和界面，提供离线单文件构建 | `tests/build.test.py`：确定性构建、无外部脚本、DOM ID 唯一、查询存在 |
| 02 | “当前日期”写死；改用设备本地日期、UTC 日期运算避免夏令时偏移 | 模型测试：上海/洛杉矶跨日、夏令时、闰日 |
| 03 | 毫秒 ID 可能撞号；使用随机唯一 ID，恢复时拒绝重复 ID | 模型测试：1000 次生成及重复恢复；排期映射无原型继承 |
| 04 | 数据恢复缺少阶段完整性检查；统一检查真实日期、周期边界和包含端点的重叠 | 模型测试：无效日期、越界、重叠、合法排序 |
| 05 | 资料地址缺少安全规范化；仅接受无凭据 HTTP(S) 链接，按真实域名匹配标识 | 模型测试：控制字符、协议、凭据、伪造路径与合法域名 |
| 06 | 事项与完成数组不匹配时显示错误进度；保存和恢复时校验类型与长度 | 模型测试：错位数组、非布尔状态拒绝 |
| 07 | 16 条和约 14.5 KB 限制会丢内容；移除人为截断，完整保存 | 模型测试：100 个需求、超过旧限制的实际序列化与恢复 |
| 08 | 更新可能丢失旧原型记录；读取 v4 并转换为 v5，保留旧记录 | 存储测试：旧记录不变，转换后可再次恢复 |
| 09 | 保存失败却关闭编辑器；失败显式反馈，先持久化后替换界面状态 | 存储测试：模拟额度异常，旧主记录保持完整；桌面运行回归继续验证表单 |
| 10 | 损坏或未来版本数据被误覆盖；保留原始记录，从有效备份恢复，无法恢复时阻止覆盖 | 存储测试：主记录损坏、有效备份、全部损坏、未知版本 |

上述模型测试 9 项、构建测试 1 项通过。测试覆盖数据逻辑，不等同于全部桌面交互已通过。

## 第三批：macOS 宿主（21–25）

| 轮次 | 问题与改动 | 验证证据 |
| --- | --- | --- |
| 21 | 浏览器页面缺少桌面窗口能力；加入 AppKit / WKWebView、真实标题栏、最小尺寸和窗口尺寸记忆 | `.app` 编译并运行；系统辅助功能树识别关闭、缩放、最小化；检查实际窗口 |
| 22 | 缺少原生菜单；加入文件、编辑、显示、窗口菜单，与相同应用命令衔接 | 通过系统菜单“文件 → 新建需求”打开编辑器；原生文本编辑菜单沿响应链工作 |
| 23 | 资料链接可能替换应用页面；只允许本地入口留在宿主，HTTP(S) 资料交给默认浏览器 | `tests/link-policy.swift` 8 个策略用例通过；导航与新窗口委托共用策略。未向真实资料网站提交数据 |
| 24 | 退出会丢失草稿；关闭与退出都先检查脏表单，使用原生保存提示 | 实际点击关闭窗口出现 NSAlert；取消后内容保留；保存后原测试进程以 0 退出 |
| 25 | 缺少可运行应用工程与 Dock 图标；提供可重复源码构建、架构目标、完整 ICNS 图标和临时签名 | Swift 构建通过；标准多尺寸图标打包通过；需在允许系统图像服务的正常环境中构建 |

实际鼠标回归另验证了单击 10 月 20 日创建单日需求、10 月 6 日到 14 日的跨周拖动、14 日到 6 日的反向跨周拖动；均正确预填 6–14 日范围，取消后回到有效日期焦点。

第二批 WebKit 回归的 21 个断言通过（包含第 09 轮的保存失败重试和正常月历适配窗口检查）。这些证据不覆盖尚未完成的独立数据文件、备份导入导出或系统通知。

剩余 26–50 轮会围绕本机数据文件与备份恢复、必要提醒、密集排期与跨月边界、深浅色和辅助操作进行。具体问题需经过检查确认后才计入轮次；不为凑数添加协作平台、AI、统计面板等功能。

# 50 轮优化记录

目标：改善交互体验与桌面原生体验；仅增加程序员管理需求所需的功能。每轮需有实际改动和验证，不以重复检查或重命名充数。

持续保留：月历主视图、顶部单一加号、连续需求长条、条内阶段、自定义资料、紧凑滚动编辑器、点击/正反拖动创建、编辑期间保留范围条、无整格选中背景、减少动态效果偏好。

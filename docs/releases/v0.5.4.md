# 需求日历 0.5.4

Windows 新增原生命令行 `reqcal.exe`，随安装包提供，使用时无需安装 Node 或 Python。安装器将应用目录加入当前用户 PATH，安装后重新打开终端即可使用。

```powershell
reqcal schema
reqcal list
reqcal create --file requirement.json
reqcal update REQUIREMENT_ID --file patch.json
reqcal export --output backup.json
```

支持与 Mac 相同的查询、新建、修改、整体平移、删除、JSON 导入预览、导入和导出，以及原始结构化指令。写入成功返回前完成持久化，界面同步刷新；未保存草稿、版本冲突和忙碌状态会阻止覆盖。

Windows 使用当前用户专用的本机命名管道，拒绝远程连接。应用未运行时，CLI 会后台启动同目录的应用；正常打开应用可显示窗口。卸载仅清理安装器自行添加的 PATH 项。

Windows 数据继续保存在 `%APPDATA%\RequirementCalendar\data`，Mac 数据目录和命令行保持兼容。Mac 安装包同步版本号，保留现有切月动画、JSON 功能与 Swift CLI。

下载 Windows x64 安装器；Mac 使用 Apple Silicon 的 DMG 或 PKG。Mac 包仍未进行 Developer ID 签名和公证。复杂 JSON 推荐使用 UTF-8 文件，避免不同终端对引号的处理差异。

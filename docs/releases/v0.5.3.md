需求日历 0.5.3 可下载安装，无需编译源码或安装开发环境。

### Mac（Apple Silicon / M 系列，macOS 15 或以上）

- **推荐：`RequirementCalendar-0.5.3-macOS-arm64.dmg`**。双击打开，将“需求日历”拖到旁边的 Applications，再从“应用程序”启动。
- 也可使用 `RequirementCalendar-0.5.3-macOS-arm64.pkg`，双击后按安装向导操作。
- 当前不包含 Intel Mac 版本。
- 本版尚未做 Apple Developer ID 签名和公证。首次打开如被拦截，确认下载来自此发布页后，可按 [Apple 说明](https://support.apple.com/zh-cn/102445)，进入“系统设置 → 隐私与安全性 → 仍要打开”。

### Windows（x64）

下载 `RequirementCalendar-0.5.3-x64-Setup.exe`，双击后选择安装目录。安装器会创建开始菜单快捷方式。

更新前先退出旧版。需求保存在用户本机数据目录，更新应用会保留原有记录。随附 SHA256SUMS.txt 可用于核对下载文件。

### 本版变化

- 上下滑动切换月份，加入跟手预览、回弹和连续过渡。
- 修复反向上滑被拦截、到达边缘后需要再滑一次的漏判。
- 今天高亮，非本月日期置灰，修复应用图标黑边。
- JSON 导入导出取代 Excel 导出，移除汇总页的待办时间节点区域。
- macOS 包内包含 reqcal 命令行工具，供 AI 或脚本操作已保存的需求。

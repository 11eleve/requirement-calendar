# 需求日历 0.6.0

新增日历内的 AI 助手：连接自己的 DeepSeek API Key，在对话中查询、创建、修改、整体平移和删除需求。使用官方 DeepSeek Harness SDK `0.2.1-rc.3`，结合当前日期、时区、月份、工作习惯与可继续的会话历史。

读取、创建、修改、删除权限分别设置，默认只读；操作结果显示在对话中，并可直接打开对应需求。支持停止、新对话和历史恢复。所有变更复用日历已有的校验、草稿保护、revision 检查、原子保存和备份。

助手设置可开启带 Bearer 令牌的本机 HTTP API，提供需求查询和增删改接口。API 仅监听 127.0.0.1，与助手共用操作权限，写操作需要 If-Match。

Mac 使用钥匙串保存模型密钥，Windows 使用系统加密存储。需求、工作习惯和对话历史本机保存；模型调用会将消息与授权读取的日历内容发送到用户配置的服务。使用自己的模型账户，不包含免费 API 额度。

README 已重新整理，涵盖产品用途、安装、首次使用、助手设置、API、命令行和开发方法。

安装包包含 AI 运行时，用户无需另装 Node 或 Python。Windows 提供 x64 安装器；Mac 提供 Apple Silicon、macOS 15+ 的 DMG 和 PKG。Mac 包仍未进行 Developer ID 签名和公证。
